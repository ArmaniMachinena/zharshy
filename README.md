# Жаршы — деловые мероприятия Казахстана

*Жаршы* — глашатай, который объезжал аулы и объявлял людям важные вести. Сервис делает то же самое для деловых событий: форумы, выставки, конференции, конгрессы, саммиты, вебинары по всем городам Казахстана.

## Как устроено
```
источники ──► паук (каждые 3 ч, GitHub Actions) ──► Claude вытаскивает поля ──► склейка дубликатов ──► data/events.json ──► сайт (GitHub Pages)
```
- `index.html` — сайт: слева «Назар аударыңыз!» (сегодня / завтра / 5 дней / мои), справа список и календарь с фильтрами по городу, отрасли, уровню, формату, датам. ☆ — следить, «+ Google Календарь» и .ics с напоминанием за сутки.
- `spider/run.py` — паук; `spider/sources.yaml` — список источников (добавлять строками).
- `.github/workflows/spider.yml` — каждый час Telegram и заявки, раз в 3 часа все источники; кнопкой — полный проход.
- `build.py` — собирает `dist/index.html` со встроенной базой (одна страница без сервера).

## Запуск
1. Settings → Secrets → Actions: `ANTHROPIC_API_KEY`.
2. Settings → Pages: ветка `main`, папка `/`.
3. Публичный сайт: репозиторий zharshy-web (Pages). Секрет `WEB_TOKEN` — fine-grained токен с правом Contents: write только на zharshy-web.
4. Actions → «Жаршы — паук» → Run workflow.

## Этапы
1. **MVP (сейчас):** сайты выставочных компаний, gov.kz, invest.gov.kz, Astana Hub, агрегаторы + открытые Telegram-каналы (t.me/s/…). Дашборд, фильтры, избранное, календарь.
2. **Приём анонсов:** Telegram-бот — пересылаешь ему анонс из любого чата (в т.ч. из WhatsApp), бот разбирает и добавляет. Форма для организаторов. Модерация.
3. **Личный кабинет:** вход через Telegram/телефон (Supabase), подписки по отраслям и городам, напоминания за 7 дн / 1 дн / 1 ч, утренняя сводка в Telegram, PWA-уведомления.
4. **Соцсети:** Facebook/Instagram/TikTok — только через официальные API и партнёрство с организаторами: собирать чужие посты правила этих платформ не разрешают. Чтение WhatsApp-групп через API невозможно — их закрывает пункт 2 (пересылка).
5. **Казахский интерфейс, API для партнёров, аналитика:** какие отрасли растут, какие площадки загружены.
